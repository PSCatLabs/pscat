## Projects

- **[pscat](https://github.com/PSCatLabs/pscat)**: PostScript for precision and
  imagination. A modern PostScript interpreter in Rust that renders PostScript
  and EPS to PNG, SVG and PDF, from the command line, as an embeddable Rust
  library, in the browser via WebAssembly, or through MCP for AI agents. It is
  the engine the lab's other tools build on.

More tools for documents and for art, built on pscat, will be listed here as
they ship.

## Try pscat

```sh
cargo install pscat          # the pscat and pscat-mcp commands
npm install pscat            # the WebAssembly renderer for browsers and Node
```

Or run it with nothing installed in the
[playground](https://pscatlabs.github.io/pscat/playground.html). The
[site](https://pscatlabs.github.io/pscat/) has the docs, the gallery and a
specimen of every font.

## Art made with pscat

Finished artwork made with pscat lives in the
[ArtColony](https://github.com/ArtColony) organization. The
[pscat gallery](https://pscatlabs.github.io/pscat/gallery.html) shows what the
engine and its libraries can do.
