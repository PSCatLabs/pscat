# pscat guides

How to use pscat and its art libraries. Start with *Getting started*; every
other guide stands on its own, and the library guides assume you have
skimmed [artkit](artkit.md) (it is the base most of them load).

## Using pscat

- [Getting started](getting-started.md): build or install pscat, the
  command-line flags, the live window, and PNG, SVG and PDF output.
- [pscat in the browser](browser.md): the WebAssembly build and a JavaScript
  quick start.
- [pscat for AI agents](agents.md): the skills, the `pscat-mcp` server and how
  to register it.

## Text and fonts

- [Fonts](fonts.md): the Type 3 display faces, the typewriter and the 61-face
  catalog.
- [Handwriting](handwriting.md): a string in, a handwritten PNG out, and the
  `/HandScript` font.
- [Lettering, headlines and apparel](lettering.md): display type with
  textured fills, headline layout, shirts and jerseys.

## Making art

- [artkit](artkit.md): the generative-art toolkit (randomness, palettes,
  turtle graphics, L-systems, path brushes, tilings, fractals, flow fields,
  scatter).
- [Style packs and page templates](style-packs-and-templates.md): four
  ready-made aesthetics and five document templates.
- [Painting](painting.md): variable-width brushes, wash and watercolor.
  - [Landscape cookbook](landscape-cookbook.md): how to paint each element of
    a landscape.
- [Printmaking and etching](printmaking.md): engraving, hatching, stipple,
  halftone, woodcut and linocut.
- [Dry media](dry-media.md): chalk, crayon, charcoal, single-stroke glyphs and
  TeX math as chalk.

## Charts

- [Charts and plots](charts.md): function plots, surfaces and bar, line, pie
  and scatter charts.
