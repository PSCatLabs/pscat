TYPE BECOMES TERRAINLIVE PSCAT / WASM
What you are changing

Typography is geometry.
Advice is observation.

Type becomes terrain. Map each character into a string and measured advance. Fold those advances to get the run width, then fold a private layout builder into glyph records. Curry a colour-field dictionary into the drawing quotation and visit the records with fp-each.

Each glyph becomes a real outline through charpath. It clips a colour gradient and contour lines; repeated offsets build the dimensional shadow. Changing the words rebuilds the measured layout. Changing the palette reuses it.

The observable press. The original row calls the target directly. The second row decorates it: before advice validates font size, after advice counts normal returns, around advice optionally draws measured ink bounds, and an outer counter records attempts.

With SIGNAL and the fault enabled, real execution gives seven attempts, six returns and one rejection. Turn the fault off: six, six, zero. Change the word: the counts follow its actual length. Diagnostics change the proof view, not the original target procedure.
