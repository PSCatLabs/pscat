# Operators in tests/data/plrm_operators.txt that pscat's systemdict does not define, and why.
# Read by tests/plrm_operators.rs. Format, tab separated:
#   missing  <name>  <#issue | untracked>  <note>   a gap to close; the issue tracks it. `untracked`: no issue yet (none today).
#   omitted  <name>  -                       <why>    a decision not to define it in systemdict (PLRM decides, gs cross-checks).
# The test fails when a PLRM operator is absent and not listed here (newly missing), and when a listed name is now defined
# (delete its line; the list must not rot). Level 3 (`languagelevel` 3, #1280) needs every `missing` line gone.
#
# Decisions where gs and the PLRM disagree (the PLRM decides):
#  * gs lacks, PLRM lists: the CIDInit, BitmapFontInit, Trapping and ColorRendering procedure-set members, StartData,
#    UserObjects and exitserver. They are PLRM 8.2 entries but are not systemdict names (a procedure set or userdict
#    member), so they are `omitted`, except exitserver, which is `missing` (#1270 tracks it; the test probes it in serverdict).
#  * gs defines, PLRM does not list: 187 non-dot names (command-line switches such as NOPAUSE, the PDF interpreter,
#    `.`-less extensions such as rsearch, max, min). They are outside the PLRM list, so the test ignores them.
#  * Names the PLRM index lacks and so needs no entry: Display PostScript extras and the Level 1 statusdict members
#    (setpageparams, setpapertray, ...) are not in the PLRM third edition's operator details.
#  * exitserver is probed in serverdict, where the PLRM and gs put it (see HOME_DICT in the test).
#  * Not carried over from the PLRM: the 27 error names (typecheck, VMerror, ...) are not operators
#    (handleerror is one of them and is also a systemdict procedure; the test does not check it); DeviceGray, DeviceRGB,
#    DeviceCMYK and /Font are names inside signatures, not operators.
