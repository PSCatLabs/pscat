Watch PostScript draw itself.

PostScript is the language printers once spoke: a page is a program that draws it. pscat is a PostScript interpreter written in Rust. Run a program and the picture appears stroke by stroke, in a window, in your browser tab, or as a PNG, SVG or PDF.

What you can make with it

Generative art Turtle graphics, L-systems, noise and flow fields, plus brushes that behave like watercolor, chalk, charcoal and ink. The gallery is all of it, rendered by pscat itself.
Type and lettering Original display faces where every letter is a small program, a handwriting font where no two letters match, and a catalog of open fonts. See Fonts.
Charts for papers Function plots, surfaces, bar, line, area, scatter and pie charts as clean vector figures. Try the interactive demos.
A tool for agents A command-line renderer, a skill for coding agents and an MCP server, so an AI can draw, look at the result and refine it. See For agents.

Install it

The playground needs nothing. To run the real thing, with the live window and every output format:

git clone https://github.com/jeromebanks/postscript_interpreter
cd postscript_interpreter
cargo run --release -- --page 500x500 examples/sierpinski.ps   # watch it draw
cargo run --release -- --png out.png file.ps                   # headless render
cargo run --release -- -i                                      # REPL + live window

What is inside

live window PNG · SVG · PDF out runs in the browser (wasm) Type 1 · Type 3 · TrueType text save / restore VM image filters MCP server and agent skills tested against Ghostscript

  • The language. A from-scratch Level 2 interpreter: three stacks and an explicit frame stack (no recursion), catchable errors with the standard PostScript names, and save / restore built on copy-on-write journaling. Architecture explains the design.
  • Graphics. Paths, fills, strokes, clipping, dash patterns, HSB, CMYK, Indexed and Separation color, sampled images with the usual decode filters, halftone screening and multi-page documents.
  • Text. The standard base fonts, Type 3 glyph programs, and real Type 1 fonts down to eexec and encrypted charstrings.
  • Output. A live window you can page through, PNG at any dpi, SVG and PDF checked by letting Ghostscript rasterize them back, and a spool mode that watches a directory like the printer in the corner of the lab.

Why

I used to write raw PostScript by hand in college and send it straight to a LaserWriter. This is a from-scratch Rust interpreter built to relive that: watching a hand-written recursive program draw itself, live, without depending on a decades-old C codebase to do it. It is not a Ghostscript replacement, and it is happy to be checked against Ghostscript.
